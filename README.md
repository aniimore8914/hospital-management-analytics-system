# 🏥 Hospital Management Analytics System

A complete Hospital Management Analytics System built using **MySQL, SQL, Python, Pandas, and Excel** to analyze hospital operations, generate business insights, and automate KPI reporting.

---

## 🚀 Features

- Designed and managed a relational hospital database using MySQL.
- Performed SQL analysis using Joins, Subqueries, CTEs, Window Functions, and Views.
- Generated business insights for revenue, doctors, patients, appointments, and treatments.
- Automated KPI and revenue report generation using Python and Pandas.
- Exported reports to Microsoft Excel for business reporting.

---

## 🛠️ Tech Stack

- **Database:** MySQL
- **Query Language:** SQL
- **Programming Language:** Python
- **Libraries:** Pandas, MySQL Connector
- **Reporting:** Microsoft Excel

## ▶️ How to Run

1. Import the CSV files into MySQL.
2. Execute `01_database_setup.sql`.
3. Run the SQL scripts for analytics.
4. Update the MySQL connection details inside the Python scripts.
5. Run:

```bash
python hospital_kpi_report.py
```

or

```bash
python revenue_report.py
```

6. The generated Excel reports will be saved in the **reports** folder.
